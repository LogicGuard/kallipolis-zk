# Contributing

We welcome contributions to Kallipolis ZK! Please refer to the [CONTRIBUTING.md](/CONTRIBUTING.md) file in the root directory for standard guidelines.

### How to contribute:
1. **Explore Issues**: Check the issue tracker for `good first issue` tags.
2. **Development Workflow**: Set up the environment following the `README.md` and `Makefile`.
3. **Testing**: Run `make test-all` before submitting a PR.
4. **Pull Requests**: Submit PRs against the `main` branch with a clear description of the changes.
